# Task Manager

A lightweight task management application built with React + InversifyJS.

## About

I built this simple task manager to explore the integration of React's latest features with InversifyJS for dependency injection. The app lets you create, track, and manage your daily tasks with a clean, responsive interface powered by Ant Design.

## Features

- Create and manage tasks with a simple interface
- Mark tasks as complete/incomplete
- Delete tasks when no longer needed
- Persistent storage (tasks are saved to localStorage)
- Clean UI with Ant Design components

## Tech Stack

- React + InversifyJS
- TypeScript for type safety
- Ant Design for UI components
- Vite as the build tool
- Tailwind CSS for styling utilities

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
